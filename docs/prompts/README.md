# Implementation prompt sets

These are executable work instructions, not implemented features. The
[roadmap](../roadmap.md) owns delivery order and release gates; the
[backlog](../backlog.md) owns individual gaps; the architecture/contracts own
behavior; [reports](../reports/) retain evidence. Root [AGENTS.md](../../AGENTS.md)
remains the engineering entry point.

- [Maintenance refactors](maintenance/README.md): optional, not-yet-executed
  steps for application operation selection, module boundaries, host evidence
  validation and console structure, based on the 11 October source audit.
- [ESS release sequence](ess_release/README.md): historical numbered delivery
  steps with implementation/evidence dispositions; remaining gaps are in the
  current backlog rather than an instruction to rerun completed work.

Open a set's README, select the next numbered prompt and dispatch that prompt
explicitly. Preparation does not execute any prompt. Completed prompts remain
as history with their handoffs linked; inspect current code before applying a
historical recipe again. Do not run multiple numbered prompts concurrently.
